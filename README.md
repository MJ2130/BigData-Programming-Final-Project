# 빅데이터 도구를 활용한 TFT 랭크 메타 분석 프로젝트

## 프로젝트 개요

본 프로젝트는 Hadoop 기반의 빅데이터 처리 기술을 활용하여 전략적 팀 전투(TFT) 경기 데이터를 분석하는 프로젝트이다.

주요 목표는 하위 티어와 상위 티어 플레이어들의 메타 차이를 분석하는 것이다.

Riot Games API를 통해 대규모 TFT 경기 데이터를 수집하고, 챔피언 조합, 시너지, 증강체, 배치 순위 등의 데이터를 분석한다.


---

## 문제 정의

TFT 플레이어들은 티어에 따라 서로 다른 덱 조합과 운영 방식을 사용하는 경우가 많다.

본 프로젝트는 다음과 같은 질문에 답하는 것을 목표로 한다.

1. 하위 티어에서 좋은 성적을 내는 덱 조합은 무엇인가?
2. 상위 티어에서 좋은 성적을 내는 덱 조합은 무엇인가?
4. 어떤 시너지와 증강체가 높은 평균 순위를 기록하는가?

본 프로젝트는 대규모 경기 데이터를 기반으로 티어 구간별 메타 차이를 분석하는 것을 목표로 한다.

## 데이터 출처

- Riot Games TFT API
- OP.GG TFT 통계 데이터 (참고용)

수집 데이터 예시:
- Match ID
- 배치 순위
- 챔피언 조합
- 시너지 정보
- 증강체 정보
- 아이템 빌드
- 티어 정보
- 패치 버전

본 프로젝트는 100MB 이상의 경기 데이터를 수집할 예정이다.

## 데이터 수집 계획

1. Riot API를 이용하여 TFT 랭크 유저 정보 수집
2. 유저별 Match ID 수집
3. TFT 경기 상세 데이터 수집
4. JSON 또는 CSV 형태로 저장
5. HDFS에 업로드

예상 데이터 규모:
- 약 20,000 ~ 50,000 경기 데이터
- 100MB 이상의 데이터셋 확보 목표
